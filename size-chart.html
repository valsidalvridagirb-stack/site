Як виміряти розмір ноги

  1. Ввечері (нога трохи більша, ніж зранку) поставте стопу на аркуш паперу, притиснутий до стіни п'ятою.
  2. Олівцем, тримаючи його вертикально, відмітьте крайню точку найдовшого пальця.
  3. Виміряйте відстань від краю паперу (п'яти) до відмітки в сантиметрах.
  4. За таблицею вище знайдіть найближче значення CM у більшу сторону — це і буде ваш розмір.

Nike — чоловічий одяг (верх, куртки)

Обхвати тіла в сантиметрах (діапазон "мін/макс" за офіційною сіткою Nike). Обхват грудей — по найширшій частині грудної клітини; обхват талії — по найвужчій частині; обхват стегон — по найширшій частині стегон.

РозмірГрудна клітина, смТалія, смСтегна, см

Як виміряти

  1. Груди: виміряйте обхват по найвиступаючих точках грудей, тримаючи сантиметр горизонтально.
  2. Талія: виміряйте обхват по найвужчій частині тулуба, зазвичай на 2-3 см вище пупка.
  3. Стегна: виміряйте обхват по найширшій частині стегон і сідниць.
  4. Якщо ваші виміри потрапляють між двома розмірами — обирайте більший для вільнішої посадки.
